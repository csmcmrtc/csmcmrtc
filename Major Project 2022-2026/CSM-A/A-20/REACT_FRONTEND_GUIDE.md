# ⚛️ React Frontend Guide

This project now supports a modern **React JS** frontend in addition to Streamlit!

## 🚀 How to Run

### Step 1: Install Dependencies
Run the setup script (only needed once):
```bash
setup_react.bat
```

### Step 2: Start the Application
Run the start script to launch both Backend and Frontend:
```bash
start_full_app.bat
```

The application will open at:
- Frontend: http://localhost:3000
- Backend: http://localhost:8000

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Modern CSS Variables & Responsive Design
- **API Client**: Native Fetch API
- **State Management**: React Hooks (useState)
- **Design System**: Custom premium aesthetics
